1. Question: "Answer locked" (contrast fix)

Today the line is green text on white at 3.35:1, below the 4.5:1 that WCAG AA requires for text this size. There are two ways to fix it. A uses Carbon's own InlineLoading "finished" state, the same component that already shows "Sending…": smaller, grey text with a green check. B keeps today's size and weight but makes the text dark, with only the check icon green, so it stays easy to read at arm's length. I recommend B.
