# Project Context: XD Team Summer Gathering Quiz

## Project Summary

This is a lightweight interactive quiz app for an Ericsson Team Summer Gathering, focused on the World Cup 2026 and the three host countries: USA, Canada, and Mexico.

## Audience

The intended audience is Ericsson colleagues attending the Team Summer Gathering. The experience should work for a mixed group of people, not only football fans.

Quiz content should lean toward:

- Geography
- Culture
- Common knowledge
- Fun facts

Avoid making the quiz depend on deep football trivia.

This is a standalone project, completely separate from Project X / Nutrition Cockpit and any previous projects.

Do not inspect, reference, copy from, or modify files outside this project folder unless the user explicitly asks for it.

## Product Direction

The project should be:

- Lightweight
- Polished
- Easy to run during a team event
- Simple for participants to join and use
- Clear in its question flow
- Smooth for the host to operate

## Platform Direction

The target is web-first.

The primary hosting setup is likely desktop or laptop. The experience should also be mobile-friendly if participants need to interact from phones.

## Visual Tone

The visual tone should be clean, friendly, slightly playful, and not overdesigned.
